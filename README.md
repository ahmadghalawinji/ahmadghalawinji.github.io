# ahmadghalawinji.github.io

Personal portfolio and CV site — [ahmadghalawinji.github.io](https://ahmadghalawinji.github.io)

## Stack

Single-page site built with plain HTML, CSS, and vanilla JS. No frameworks, no build step.

- **Fonts** — Inter, Lora, JetBrains Mono (Google Fonts)
- **Animations** — Intersection Observer scroll reveal, CSS keyframes
- **Deployment** — GitHub Pages (auto-deploy on push to `main`)

## Structure

```
index.html                        # Everything — markup, styles, and scripts
ahmad_ghalawinji.jpg              # Profile photo
Ahmad_Ghalawinji_Research_CV.pdf  # Research-oriented CV
Ahmad_Ghalawinji_Industry_CV.pdf  # Industry-oriented CV
```
