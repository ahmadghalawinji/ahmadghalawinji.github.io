AdaptiveRAG-MA — Self-Improving Multi-Agent LLM System

Four-agent system (Memory, Planner, Executor, Critic) that learns from every run using Failure-Driven Experience Replay — successful and failed tasks are stored in a FAISS semantic index and retrieved as guidance for future similar tasks, improving without model fine-tuning. Runs fully locally via Ollama with a streaming FastAPI backend and interactive web UI with analytics, experience timeline, and LoRA export.

PythonOllama FAISSFastAPI LangChainDocker

CogniScaffold — AI-Assisted Reasoning Research Platform

Open-source research platform investigating how scaffolding strategies affect human reasoning quality when assisted by a local LLM. Implements a controlled between-subjects experiment across three conditions (baseline, uncertainty estimates, guided reflection prompts), with full telemetry collection, FastAPI backend, React + TypeScript frontend, and Jupyter notebooks for statistical analysis — designed for reproducibility in human-AI interaction research.

PythonFastAPI ReactTypeScript OllamaSQLiteDocker

Climate Change & Youth Cardiorespiratory Fitness

Prototype research pipeline for the SUPER Horizon Europe project. Integrates ERA5 climate data, World Bank socioeconomic indicators, and HEPA policy scores; generates synthetic VO2max values using physiological assumptions; trains Random Forest, XGBoost, and Linear Regression models; and simulates +1°C to +3°C warming scenarios with physical activity mitigation analysis. Includes an interactive Streamlit dashboard.

Port Calls Detection & Vessel Journey Modelling

End-to-end pipeline that detects vessel port arrivals and departures from 27,000+ AIS position records across 16 ports. Uses geodesic geofencing (20 km threshold) and time-gap deduplication to identify port call events, then infers each vessel's next destination via a SQL LEAD() window function.

PythonApache AirflowPostgreSQLStreamlitDockerGeoPy

Trend Oracle — News Q&A System with RAG

Fully local news Q&A system collecting articles from five international RSS feeds (BBC, Al Jazeera, Guardian, France 24, NYT), scraping full body text, and applying NLP pipelines for sentiment analysis and named entity recognition. Uses a RAG architecture with MiniLM embeddings and ChromaDB as a vector store for natural-language queries with cited sources. Complete data pipeline with DuckDB for structured queries, containerised with Docker Compose, and an interactive Gradio interface with streaming responses.
