Climate Change & Youth Cardiorespiratory Fitness

Prototype research pipeline for the SUPER Horizon Europe project. Integrates ERA5 climate data, World Bank socioeconomic indicators, and HEPA policy scores; generates synthetic VO2max values using physiological assumptions; trains Random Forest, XGBoost, and Linear Regression models; and simulates +1°C to +3°C warming scenarios with physical activity mitigation analysis. Includes an interactive Streamlit dashboard.

Pythonscikit-learn XGBoostStreamlit ERA5PandasPlotly

Port Calls Detection & Vessel Journey Modelling

End-to-end pipeline that detects vessel port arrivals and departures from 27,000+ AIS position records across 16 ports. Uses geodesic geofencing (20 km threshold) and time-gap deduplication to identify port call events, then infers each vessel's next destination via a SQL LEAD() window function.

PythonApache AirflowPostgreSQLStreamlitDockerGeoPy
