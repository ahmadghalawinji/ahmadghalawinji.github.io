Code Sample

Data Wrangling & Feature Engineering

Raw BTS data required careful parsing of time fields and construction of delay category features before any analysis could begin.

Python · pandas
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Load and parse BTS on-time performance data
df = pd.read_csv('bts_flights_2023.csv', low_memory=False)

# Engineer delay category buckets
def delay_bucket(mins):
    if pd.isna(mins): return 'On Time'
    elif mins < 0: return 'Early'
    elif mins < 15: return 'Minor'
    elif mins < 60: return 'Moderate'
    else: return 'Severe'

df['delay_cat'] = df['ARR_DELAY'].apply(delay_bucket)
df['dep_hour'] = df['CRS_DEP_TIME'] // 100

# Aggregate: mean delay by airline and hour
pivot = df.groupby(['CARRIER_NAME', 'dep_hour'])['ARR_DELAY'] \
          .mean().reset_index()

# Heatmap: carrier × departure hour
matrix = pivot.pivot(index='CARRIER_NAME', columns='dep_hour', values='ARR_DELAY')
sns.heatmap(matrix, cmap='RdYlGn_r', annot=False, fmt='.1f')
plt.title('Mean Arrival Delay (min) by Carrier & Departure Hour')
plt.tight_layout()
plt.savefig('heatmap_carrier_hour.png', dpi=150)
Methodology

Approach & Data Sources

The analysis used the Bureau of Transportation Statistics (BTS) On-Time Performance dataset covering 12 months of domestic U.S. flights — approximately 7 million rows after cleaning. Missing values in delay columns were treated as on-time arrivals per BTS documentation. Outliers above the 99.5th percentile (delays exceeding 6 hours) were flagged separately as diversion/cancellation candidates.

Seasonal effects were isolated using a month-of-year decomposition; daily patterns used departure hour binning. Carrier comparisons were normalized against route-level expected delay to account for network composition bias (e.g., carriers flying more weather-exposed routes).
